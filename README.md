# Git-Helfer (Powershell for Windows)

Ein einfaches Werkzeug-Set, um den Workflow mit Git und GitHub Releases zu automatisieren.

### Funktionen:
* Automatisches Erstellen von Tags.
* Synchronisation mit GitHub (Push).
* Erstellen von Releases mit der GitHub CLI (`gh`).

### Nutzung:
Einfach die `Git-Helfer-Start.bat` ausführen und den Anweisungen folgen.
